# ADR-0010：macOS 自用版仅保留明确的设备操作

日期：2026-11-06　状态：已接受

macOS 自用版移除文字与语音指令、AI 服务、GrokBall、主动推荐和习惯学习。保留米家云、Home Assistant、演示模式、设备搜索、卡片控制、快捷动作、撤销、历史读数、提醒和 Mac 状态自动化。

## 共享执行逻辑

`DeviceIntent`、`IntentOperation`、`IntentPlan` 是结构化设备操作，不再表示语言或模型输出。`HomeStore+Actions.swift` 保留能力校验、同设备顺序执行、设备间并发、乐观状态、失败回滚与逆向命令。系统自动化复用该路径。手动卡片及快捷动作保留原有控制入口，不进行习惯记录。

撤销直接调用 `undoLastAction` 或 `undoTurnAllOff`，无需解析“撤销”文字。横幅消失后仍可在十分钟内点击撤销按钮；切换连接上下文会清除两个入口。撤销失败时回滚对应界面状态并明确报告失败。

## 升级行为

- 旧文字定时不再创建或调度，包括尚未到期和已错过的任务。原始 `assistant_scheduled_commands_v1` 数据保留，设置页列出可解析的摘要，只有用户确认清理才删除。损坏的数据同样保留并显示清理入口。
- 清理退役的助手偏好、习惯、授权和 API Key。钥匙串只删除指定助手账户，不删除共享 vault、米家会话、HA Token 或 LG 配对凭据；vault 不可读时不写入，后续启动重试。
- 删除麦克风、语音识别权限声明及录音 entitlement。不调用语音服务或 AI 服务。
- App Intents 保留设备切换、场景执行和温湿度查询，移除“一句话控制”。URL 保留 `toggle`、`scene` 和原有确认机制，拒绝 `ask`。
- 全局快捷键与菜单栏点击仅呼出/收起面板。搜索只过滤设备，未知文字不会转为控制请求。

## 平台边界

本决定仅适用于 macOS。Windows 的独立实现及其语言、AI、习惯、情绪球语料保留，不再要求 macOS 实现这些已删除功能。两端仍共享 MIoT 合成/命令映射和云区域语料。ADR-0009 的习惯算法仅继续适用于 Windows。

未来若需要倒计时，可单独实现图形化定时，不恢复语言解析或模型依赖。摄像头和设备后端不在本次裁剪范围内。后续本机版已移除更新界面和后台检查，详见 `docs/qa/macos-panel-refinements-2026-11-06.md`。
