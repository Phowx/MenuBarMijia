# macOS 云同步与凭据恢复（2026-11-17）

对照 Windows 的 `411b542` / `e78e50d`，修复 macOS 的云响应校验、凭据失败处理和同步错误展示。Windows 源码不变。

## 行为

- HTTP 401、明确的会话过期码/信息要求重新登录；403、限流、服务故障和签名错误不再等同于登录过期。先检查 HTTP 状态，再处理 JSON 或加密响应。
- 顶层状态码必须是数值整数。异常设备、家庭或属性列表会抛错；明确的空列表仍有效。失败不会发布空快照，已有同一连接的数据继续显示。后端或账号变更时不沿用上一连接的设备。
- 米家后台完整同步成功后才恢复连接状态。设备、房间和属性请求失败均报告错误；临时故障继续退避重试，明确过期停止轮询。单设备追询成功不会清掉完整同步的错误。
- 钥匙串不可读、内容损坏、没有保存过凭据分别处理。不可读/损坏记录不覆盖；普通读取不重复弹授权框，由用户点击“重试凭据”才重新读取。
- 米家会话或 HA Token 保存失败时持续显示提示，不报告保存成功。新凭据只留在当前进程内供连接使用，重试成功后才清除提示；不写明文备用凭据，也不覆盖其他账号。
- HA 凭据未成功读取时，设置里的空输入框不能删除原 Token。设置和地址切换优先使用本次运行中尚未保存的 Token。
- 面板可滚动区域显示完整错误、上次状态提示、更新时间和对应恢复入口。错误按类型选择重试同步、凭据重试或连接设置，不匹配翻译后的字符串。连接设置也持续显示凭据问题。
